# bookify
- Your place to book a space!

Actualmente, muchas empresas presentan problemas en la administración de espacios compartidos como salas de juntas, oficinas privadas o áreas de coworking. La gestión manual de reservas mediante hojas de cálculo, mensajes o sistemas poco centralizados genera conflictos de horarios, duplicidad de reservaciones y poca visibilidad de disponibilidad en tiempo real. Además, los sistemas existentes suelen ser costosos, poco flexibles o no permiten integración con otras plataformas mediante servicios programables (API). Esto ocasiona pérdida de tiempo, mala organización operativa y una experiencia deficiente para administradores y clientes. 
Por ello, resulta relevante desarrollar una solución backend robusta basada en una API REST que permita automatizar el control de espacios, validar disponibilidad en tiempo real y prevenir colisiones de horarios mediante reglas de negocio seguras y centralizadas.
